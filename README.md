# BlogSphere frontend

The frontend is developed with React and Vite. Its production build bundles the
JavaScript and CSS into `dist/index.html`, so the generated page does not depend
on separate JavaScript or stylesheet files.

Run `npm run dev` from the project root for development, or `npm run build` to
generate the single-file production page. The frontend still needs the BlogSphere
API to provide dynamic content and account features.
